> 機制詳解：[us-market-guide.md](./us-market-guide.md#利率--加息宏觀分母)

### 當前你要問自己的三句話

- [ ] 接下來 3–6 個月是 **再加息 / 維持高利率 / 降息預期** 哪一種？（看 Fed 聲明、點陣、Core PCE）

- [ ] 我的標的在加息下靠 **盈利** 還是靠 **故事+融資**？（後者不宜 $5k 全倉）

### GOOGL vs SIVE（加息維度）

| | GOOGL | SIVE（SIVEF） |
|---|--------|----------------|
| 敏感度 | **低～中** | **高** |
| 護城河 | 平台+現金流，相對抗跌 | 弱～中，**易被殺估值** |
| 加息時主風險 | 廣告放緩、Capex 壓 FCF | 倍數崩、增發稀釋、Pipeline 不轉化 |
| $5k 全倉 | **較適合** | **不建議** |
| 與「AI Capex」 | 自己是 **花錢方** | 要等 **拿單** 才受益 |

- [ ] 若你判斷 **再加息或 Higher for longer** → 維持 **GOOGL ①**，勿因便宜改全倉 SIVE  
- [ ] 若 **降息預期升溫** → SIVE 可能反彈更快，但仍建議 **小倉**；$5k 規則下 GOOGL 仍較穩

### 宏觀否決（任一觸發 → 暫緩買入或縮倉）

- [ ] GOOGL：財報同時 **下調廣告或 Cloud 指引**（公司+宏觀雙殺）
