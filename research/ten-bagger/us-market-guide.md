# 美股 10 倍股研究備忘

本庫**以美股為主**（NYSE / NASDAQ；ADR 另註）。以下為填寫 `companies/*.md` 時常用的美股脈絡，非選股清單。

## 市值區間與 10x 難度

| 區間 | 典型市值 (USD) | 10x 含義 | 備註 |
|------|----------------|----------|------|
| Nano / Micro | &lt; $300M | 可能但流動性差 | 財報品質、做空風險需嚴格 |
| Small | $300M – $2B | 歷史上 10x 案例最多 | 機構覆蓋少，資訊差仍存在 |
| Mid | $2B – $10B | 需強主線 + 執行 | 常見「成長股再翻倍」起點 |
| Large | &gt; $10B | 10x 罕見 | 多靠新曲線（AI、新產品）或極低基數反轉 |

建議在檔案中寫明 **當前市值** 與 **Bull 目標市值**，避免只寫股價倍數而忽略稀釋。

## 美股常見 10x 主線（對應 `drivers`）

| 主線 | 典型板塊 | 驗證節奏 |
|------|----------|----------|
| `tam` | 新平台、能源轉型、太空、某些 SaaS | 滲透率、TAM 指引、設計贏單 (design win) |
| `volume` | 半導體週期、工業、電商 | 訂單、backlog、產能利用率 |
| `margin` | 軟體規模化、零售 turnaround | 毛利率、Rule of 40、單位經濟 |
| `multiple` | 利率敏感成長股、破產重整後 | 同業 PE/EV/Sales、Fed 預期 |
| `platform` | 市集、支付、開發者生態 | NDR、take rate、生態 GMV |
| `turnaround` | 消費、舊經濟 + 新 CEO | FCF、去槓桿、同店增長 |

## 必查美股項目（建議每檔勾選）

- [ ] **10-K / 10-Q**（[SEC EDGAR](https://www.sec.gov/edgar/search/)）— 風險因素、客戶集中度、債務契約  
- [ ] **8-K** — 融資、CEO 變動、重大合約  
- [ ] **SBC（股權激勵）** — 是否吃掉每股成長（尤其未盈利成長股）  
- [ ] **稀釋** — 可轉債、ATM、二次增發歷史  
- [ ] **做空比例 / days to cover** — 極端值需寫進 bear case  
- [ ] **財年結束月** — 避免搞錯 Q1/Q2（非自然年很常見）  
- [ ] **指引慣性** — 是否慣性 beat/raise（影響估值 premium）  

## 估值與倍數（美股習慣）

| 類型 | 常用倍數 | 注意 |
|------|----------|------|
| 盈利成長 | P/E, PEG | 負盈利時 PE 無意義 |
| 高成長未盈利 | EV/Sales, EV/GP | 與同業 stage 對齊 |
| 訂閱 / SaaS | ARR multiple, Rule of 40 | 區分 GAAP 與 adjusted |
| 金融 | P/B, P/TBV | 與利率、信貸週期綁定 |
| 生物醫藥 | rNPV / 現金跑道 | 二進制事件驅動，10x 常來自單一管線 |

## 利率 / 加息（宏觀分母）

> 填寫公司檔時，若標的 **未盈利、高 PS、依賴融資**，必寫一節「對加息/高利率的敏感度」。資料：[FRED](https://fred.stlouisfed.org/)（Fed Funds、10Y）、Fed 點陣圖、CPI 日曆。

### 機制（簡表）

| 傳導 | 加息 / 高利率 | 對誰更傷 |
|------|----------------|----------|
| **估值分母** | 無風險利率↑ → 遠期現金流折現率↑ | **未盈利、久期長** 的成長股（小盤 10x 候選） |
| **倍數壓縮** | EV/Sales、PEG 下修 | 靠 `multiple` 驅動的標的（SIVE、部分 PLTR） |
| **融資成本** | 股權/可轉債/債務更貴 | **仍虧損、需增發**（SIVE、IREN、SMCI） |
| **廣告 / IT 預算** | 宏觀走弱時企業削廣告、延長採購 | **GOOGL Search**、SNOW、PLTR（商業端） |
| **Capex 紀律** | 利率高時市場更問 ROI | **Hyperscaler** 仍可能投 AI，但 **二線供應商** 拿單更難 |
| **相對吸引力** | 現金、短債收益率↑ | 資金從 **高波動小盤** 流向 **盈利 mega / 現金流** |

### 標的類型 × 利率敏感度（本庫）

| 敏感度 | 類型 | 本庫例子 | 加息時典型反應 |
|--------|------|----------|----------------|
| **低～中** | 盈利 mega、有現金流 | **GOOGL**、NVDA（已盈利） | 倍數略壓；若業績強可相對抗跌 |
| **中** | 盈利成長、高估值 | PLTR、SNOW、ANET | 波動加大，看 guidance / NDR |
| **高** | 小盤、虧損、靠融資+故事 | **SIVE**、IREN、SMCI | 跌幅常大於指數；Pipeline 轉化放緩 |
| **高（特殊）** | 盈利但收入綁 **SOFR+加密** | **CRCL** | 加息對 **儲備利息** 與 **風險偏好** 方向可能分裂 |

### 必追宏觀指標（每季覆核）

| 指標 | 用途 |
|------|------|
| **Fed Funds 上限 + 點陣** | 政策路徑（加/暫停/降） |
| **10Y 美債收益率** | 成長股估值錨 |
| **實質利率**（10Y − 通膨預期） | 長久期資產壓力 |
| **CPI / Core PCE** | 是否迫使 Fed **再加息** |
| **美元 DXY** | 影響 SIVE（SEK/USD）、海外營收 |

### 加息情境下的 thesis 調整（寫進 bull/bear）

- **再加息 / Higher for longer**：提高 **bear 機率** 給高 PS、無盈利標的；mega 盈利股改看 **FCF 與 Capex ROI**。  
- **降息預期升溫**：成長/小盤 **估值修復**，但需區分「炒降息」vs「盈利跟上」。  
- **AI Capex 特例**：NVDA/雲廠 Capex 可與宏觀脫鉤數季；**Sivers 類上游** 仍受「設計贏單 + 融資」雙重約束，不能假設 Capex↑ 就必 10x。

### $5k 單倉（利率維度）

| 標的 | 加息環境下的相對優勢 |
|------|----------------------|
| **GOOGL** | 有盈利與品牌現金流；痛點在 **Capex 壓 FCF**，非「借不到錢」 |
| **SIVE** | 無盈利、靠增發；加息 → **稀釋成本↑ + 倍數↓**，不宜全倉 |
