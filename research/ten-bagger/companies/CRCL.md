## 一句話論點

> **USDC** 發行與合規穩定幣基建龍頭候選；Q1’26 收入+儲備收益 **$694M**（+20%）、USDC 流通 **$77B**（+28%）、鏈上量 **$21.5T**（+263%），並押注 **Arc L1 + AI Agent 支付**——但收入高度依賴 **準備金利息（SOFR）**，淨利波動、與 **USDT** 競爭及監管仍關鍵；**10x 難**（已上市且市值不低），合理想像 **2–5x** 若穩定幣滲透 + 立法順風。

## 公司做什麼

| 產品/線 | 內容 | 變現方式 |
|---------|------|----------|
| **USDC** | 美元穩定幣（與 Coinbase 等共同推動） | 準備金投資收益（Reserve Income）；流通量驅動 |
| **CPN** | Circle Payments Network | 支付量、機構接入（Q1 年化 TPV 約 **$8.3B→$10B**） |
| **Arc + ARC token** | 穩定幣原生 L1；預售 **$222M** @ FDV **$3B** | 長期協議收入、代幣會計（指引外） |
| **Circle Agent Stack** | Agent 錢包、Nanopayments、x402 代理支付 | 訂閱/服務、交易費（仍小） |
| **EURC / USYC** 等 | 歐元穩定幣、代幣化貨基 | 擴品類 |

## 護城河

| 強項 | 弱點 |
|------|------|
| **USDC** 合規敘事、機構採用（Visa 分析中商用穩定幣流量占比高） | **Tether (USDT)** 流通量仍更大、鏈上習慣強 |
| 與 **Coinbase**、銀行/支付夥伴生態 | 收入結構依賴 **準備金利率**，非純「交易費護城河」 |
| 監管立法順風（GENIUS、CLARITY 等討論） | 穩定幣法案細節、儲備與贖回規則不確定 |
| 鏈上 **流速** 與整合（Meta、DoorDash、Polymarket 等案例） | Q1 流通量 **環比持平**；加密市場 beta |
| AI 代理支付敘事（x402、USDC 結算占比） | Arc/代幣經濟複雜度、會計與監管風險 |

**結論**：**中等偏強（合規穩定幣賽道）**，但 **非半導體式硬寡占**；10x 需 **USDC 規模數倍 + 非利息收入占比上升**。

## 為何納入觀察（與 AI 板的關係）

1. **AI × 鏈上經濟**：管理層主打 AI Agent 需可編程支付；Circle Agent Stack、x402。  
2. **非半導體 AI 受益標的**：與 NVDA/GOOGL 低相關，可作組合分散。  
3. **政策催化**：美國穩定幣框架進展 → 合規發行方受益敘事。  
4. **與加息主題強相關**：見下節（與 GOOGL/SIVE 機制不同）。

## 利率 / 加息敏感度（**高 · 結構特殊**）

| 通道 | 加息 / 高利率 | 降息 / 低利率 |
|------|----------------|----------------|
| **Reserve Income** | 準備金收益率↑ → **單位 USDC 收入↑** | SOFR↓ → 已見 **-66 bps YoY** 拖累 |
| **USDC 需求** | 高利率時 crypto 槓桿降 → 流通量可能承壓 | 風險資產活躍或利好鏈上活動 |
| **估值** | 成長/金融科技 PE 仍受分母影響 | 估值修復，但 **利息收入下降** |
| **vs GOOGL** | GOOGL：痛 **Capex/FCF**；CRCL：痛 **淨利對 SOFR 敏感** | |
| **vs SIVE** | 兩者皆高 beta；CRCL **有盈利**，SIVE **仍虧損** | |

**再加息**：可能 **利好 Reserve Income 假設**，但 **打壓加密風險偏好** → 流通量與股價未必同向。  
**Higher for longer**：宜同時追 **SOFR、USDC 流通、RLDC margin**。

## 三情形（股價倍數 — 主觀）

| 情形 | 機率 | 目標倍數 | 預期年份 | 核心假設 |
|------|------|----------|----------|----------|
| Bull | 25% | **4–6x** | 2030–31 | USDC $150B+；立法順風；CPN/Agent 收入占比升；Arc 成功 |
| Base | 50% | **1.5–2.5x** | 2030 | 流通穩增；利息中性；估值隨盈利 |
| Bear | 25% | **0.4–0.6x** | 2027–28 | 加密寒冬；USDT 擠壓；利率+監管雙殺；Arc/代幣爭議 |

> **不設 10x Base**：已上市 large cap 金融基建，10x 需極端 USDC 滲透 + 估值泡沫，單獨列 Bull 上限即可。

### Bull

1. 美國穩定幣法案落地，USDC 份額升  
2. 非儲備收入（訂閱、CPN、Arc）連續超預期  
3. AI 代理支付成標準，Circle 為默認結算層之一  

### Base

1. USDC 高單位數～低雙位數年化增長  
2. Reserve Income 隨利率與流通量波動  

### Bear

1. 數字資產長熊，流通量縮或份額丟給 USDT  
2. 儲備收益率持續下行、費用增速 > 收入  
3. 監管處罰或 Arc/代幣結構引發信任危機
