# 泰文聽力小遊戲

瀏覽器裡的泰文聽力四選一遊戲：聽泰文發音，選出正確的中文意思。

## 功能

- 單字：八大主題共 **465 詞**，每輪最多 30 題；答題後顯示 **2 則例句**，並標註同音字、同字不同義、易混淆詞；另有「易混淆專練」
- 進階句子：五大主題共 **194 句**，每輪最多 15 題；答題後可展開 **句子分析**（分段、語法角色、**組合字拆解**、說明）
- 短文章：**18 篇**（旅遊、日常、飲食、文化），可閱讀全文（K 歌字幕）並測驗，每輪最多 10 題、答對 +18 分
- 首頁可切換「單字 / 句子 / 短文 / 基礎」，錯題分開複習
- **基礎教學**：元音、聲調（學習＋測驗）、發音技巧（18 則要訣與範例朗讀）
- 題目區顯示泰文字與**帶聲調的羅馬拼音**（如 `sàng`、多音節 `khòp-khun`，並標平/低/降/高/升），搭配 Web Speech API 朗讀（`th-TH`）
- 本機進度：總分、最高分、連續答對、錯題複習

## 開發

```bash
npm install
npm run dev
```

瀏覽器打開終端顯示的網址（通常是 http://localhost:5173）。

## 建置

```bash
npm run build
npm run preview
```

## 語音提示

泰文發音依賴系統與瀏覽器的語音引擎。建議使用 **Chrome** 或 **Safari**，並在系統設定中安裝泰文語音包。
